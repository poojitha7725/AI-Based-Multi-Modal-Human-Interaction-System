📖
Welcome! This is your complete beginner's guide.
Follow these steps one by one. You do not need any coding knowledge. Just read and click!
🚀 Step 1 — Getting Started
1
Open the web app
After starting the Flask server, open your browser and go to http://127.0.0.1:5000. You will see a login page.
2
Register or Login
If you are new, click "Register" and fill in your name, email, and password. Then log in. You will be taken to the Dashboard.
3
Check System Status
Click "System Check" in the left sidebar to see if your camera, microphone, and all Python libraries are working correctly before using any features.
📊 Step 2 — Using the Dashboard
1
Module Status Cards
The dashboard shows 4 cards: Gesture Module, Voice Module, Facial Module, Virtual Mouse. Each card has a Start and Stop button. Click Start to activate a module.
2
Live Camera Feed
Click the "Activate Camera" button on the dashboard to see the live camera feed. You can switch between Gesture / Facial / Virtual Mouse modes using the dropdown.
💡 Tip: Start just one module at a time when you are learning. Do not start all modules together — it may slow down your computer.
🎤 Step 3 — Using the Voice Assistant
1
Go to Voice Assistant page
Click "Voice Assistant" in the left sidebar.
2
Start the Assistant
Click the green "▶ Start Assistant" button. The status will change to "Active".
3
Click the Microphone button
Click the 🎤 microphone button. It will turn 🔴 red and show "Listening... speak now". Now speak your command clearly.
4
Supported Voice Commands
Speak one of these commands clearly and slowly:
"open youtube" "open google" "open calculator" "open notepad" "play music" "pause music" "scroll up" "scroll down" "take screenshot" "stop assistant"
5
Test Without Microphone
If your microphone is not working, use the "Test a Command Manually" text box. Type any command (e.g. "open youtube") and click Send. This will execute the command.
⚠️ If microphone does not work: The system uses sounddevice (already installed). Make sure your microphone is plugged in and not muted in Windows Sound Settings. You also need an internet connection for Google Speech recognition.
🖐️ Step 4 — Using Hand Gesture Recognition
1
Go to Hand Gestures page
Click "Hand Gestures" in the sidebar.
2
Start Detection
Click "▶ Start Detection". Your webcam will turn on and show a live feed with green skeleton drawn on your hand.
3
Perform Gestures
Hold your hand clearly in front of the camera. Try these gestures:

💡 Tip: Keep your hand 30–60 cm from the camera. Make sure there is good lighting. Keep fingers clearly separated for best recognition.
😊 Step 5 — Using Facial Expression Detection
1
Go to Facial Expression page
Click "Facial Expression" in the sidebar.
2
Start Detection
Click "▶ Start Detection". Your webcam will start and the AI will try to detect a face.
3
Make facial expressions
Sit in front of the camera with good lighting. Make expressions like smiling 😄, frowning 😠, or showing surprise 😲. The detected expression and confidence percentage will appear on screen.
💡 Tip: The system uses DeepFace AI (if installed) for accurate detection. If DeepFace is not available, it uses OpenCV rules as a fallback. Results may be less accurate with OpenCV fallback.
🖱️ Step 6 — Using Virtual Mouse
1
Go to Virtual Mouse page
Click "Virtual Mouse" in the sidebar.
2
Enable Virtual Mouse
Click "▶ Enable Virtual Mouse". Your camera will turn on.
3
Control the Mouse with your hand
Move cursor: Raise only your index finger ☝️ — move hand to move the cursor.
Left click: Raise index + middle finger ✌️ and bring them close together.
Right click: Raise index + ring finger (skip middle).
Scroll: Raise index + pinky finger 🤙.
4
Adjust Sensitivity
Use the Cursor Sensitivity slider on the left. Higher value = cursor moves faster. Lower value = more precise control. Start at 1.5× (default).
⚠️ Important: The virtual mouse will actually move your real computer cursor. If the cursor gets stuck, move your hand out of frame or click "⏹ Disable" button. Set PyAutoGUI FAILSAFE to False is already done for you.
⏹️ Step 7 — Stopping Features Safely
1
Stop any module
Every page has a red "⏹ Stop" button. Click it to stop that module. This will turn off the camera stream and stop detection for that module.
2
Stop the whole server
Go to the terminal where you ran python app.py and press Ctrl+C. This will stop the Flask server and close all camera connections safely.
